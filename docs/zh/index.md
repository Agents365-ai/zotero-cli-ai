# zot — 适配任意 AI Agent 的 Zotero 命令行工具

`zotero-cli` 是一个适配任意 AI Agent 的 Zotero CLI 工具。

**核心特性：**

- **读取**：直接访问本地 SQLite 数据库 — 零配置、离线可用、毫秒级响应
- **写入**：通过 Zotero Web API 安全写入 — Zotero 完全感知变更
- **PDF**：从本地 PDF 存储中提取全文，支持自动缓存
- **工作区**：对 Zotero 集合进行自然语言排序检索 — 无索引，结果始终最新
- **MCP**：39 个工具，支持 AI 编程助手（Claude Desktop、Cursor、LM Studio）

**无需启动 Zotero 桌面端即可搜索和阅读论文。**
